# 🌍 Climate Scope — Global Warming Analytics Dashboard

An end-to-end data analytics and visualization project designed to analyze global warming drivers, greenhouse gas emissions, temperature anomalies, and socioeconomic indicators.

---

## 📌 Project Overview
**Climate Scope** tracks and visualizes global environmental trends over time. By combining multi-source climate datasets—including sector-wise carbon/methane emissions, energy transition indicators, and extreme weather metrics—this project delivers actionable insights through an interactive executive dashboard.

## 🛠️ Tech Stack & Architecture
- **Data Processing & ETL:** Python (Pandas) / SQL
- **Data Storage & Warehousing:** SQL Server Data Warehouse
- **Visualization & Business Intelligence:** Power BI

---

## 🗓️ High-Level Project Phases

- **Phase 1: Requirements & Data Gathering:** Project initiation, raw data acquisition, and initial wireframing.
- **Phase 2: Preprocessing & Data Staging:** Data cleaning, unit standardization, and staging environment setup.
- **Phase 3: Database Integration & Analytics Logic:** Database modeling, metric calculations, and DAX implementation.
- **Phase 4: Final Integration, Testing & Presentation:** System verification, performance optimization, and final dashboard presentation.

---

## 📊 Key Features
- **Historical Baseline Comparisons:** Tracks temperature and emission deviations relative to pre-industrial levels (1850–1900).
- **Multi-Dimensional Filtering:** Slice data by geographic region, gas type, economic sector, and custom date ranges.
- **Executive Storytelling:** High-level KPI indicators and visual trends highlighting renewable energy transition and severe events.
